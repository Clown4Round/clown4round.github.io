# clown4round.github.io
Clown's guide to UnderSpeak, the discord text to sound byte bot!

UnderSpeak is a discord bot, functioning similarly to a TTS bot, but with Undertale sound bytes for the voice! Annoy your friends, goof around, and have fun with it!
All sounds and characters belong to Toby Fox.
Sounds are gotten from the following: https://sounds.spriters-resource.com/pc_computer/undertale/asset/399803/
